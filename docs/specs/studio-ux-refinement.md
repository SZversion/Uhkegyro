# Studio UX 보완

## Why
홈 카드 겹침, 모바일에서 결과까지 긴 스크롤, 브랜드 버튼의 상이한 동작과 유사 기록 구분 문제를 해결한다.

## Goal
기존 색상·두꺼운 경계·검색 API를 유지하면서 여섯 UX 개선을 적용한다.

## What
- 충분한 보드 폭에서는 부채꼴, 부족하면 겹치지 않는 카드 그리드.
- 모바일은 레퍼런스/대화 전환과 별도 기록 버튼, 각 영역 독립 스크롤.
- 모든 UH 버튼은 홈 이동, 기록은 기록 버튼으로만 접근.
- 기록에는 현재 목록의 요청 순번을 표시한다. 시간은 추측하지 않는다.
- 보조 문구의 색상·여백·크기로 위계 개선. 브랜드 경계는 유지.
- 실패 재시도는 원문을 입력란에 복원하고 포커스한다. 자동 전송하지 않는다.

## How
page.jsx, ConversationPanel.jsx와 globals.css만 변경한다. 서버 계약·LLM은 변경하지 않는다. container query로 보드 자체의 폭에 대응한다.

## AC
- 홈 카드가 서로 겹치지 않으며 모든 용어를 선택할 수 있다.
- 모바일 탭으로 긴 대화를 스크롤하지 않고 결과에 접근하며 숨긴 영역은 포커스 대상에서 제외된다.
- UH 클릭은 홈 이동, 기록 버튼은 기록 열기.
- 동일 문장의 두 기록에 서로 다른 요청 번호가 표시된다.
- 실패 재시도 클릭은 원문을 복원하지만 API 요청을 생성하지 않는다.
- 프론트 테스트·빌드·diff 검사 통과. 실제 UI 검사는 유료 LLM 호출 없이 수행한다.

## 검증 결과 (2026-10-02)
- 기존 프론트 테스트 45개 통과, production build와 diff 검사 통과.
- 1440px 부채꼴과 1100px 그리드에서 카드 사각형의 교차 0건 확인.
- 모바일 레퍼런스/대화 전환 시 숨긴 패널은 접근성 트리에서 제외된다.
- 390px 결과 화면의 문서 너비와 scrollWidth가 모두 390px. 갤러리는 독립 스크롤이며 기존 기록의 핀 16개를 복원했다.
- 실패 재시도는 원문 44자를 입력란에 복원하고 포커스했다. 전송하지 않았으며 기존 요청 두 건은 유지됐다.
- 기록 요청 1/2 구분, 별도 기록 열기와 Escape 닫기, 브랜드 홈 이동 확인.
- 검사는 기존 기록 조회로 진행했다. 새 LLM 호출·commit·push는 하지 않았다.
