## 프롬프트 버전 차이

| 버전 | 달라진 점 |
| --- | --- |
| **v0** | 기본 역할과 JSON 계약을 정했다. 활성 TERM_CARD만 선택하고 역할별 최대 하나를 반환한다. 단서가 부족하거나 상충하면 질문하며, 최종 API 상태·검색어·URL은 resolver가 맡는다. |

| **v2** | 근거를 연속된 원문 부분 문자열로 복사하고 역할당 단일 카드를 선택하도록 강화했다. 한 자세의 요소를 포즈 카드 여러 개로 중복 표현하지 않는다. 바닥에 기대어 누운 자세는 일반적인 바닥 지지보다 `pose_reclining`을 우선한다. |
