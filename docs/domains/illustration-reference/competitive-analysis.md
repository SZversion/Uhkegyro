# 경쟁 서비스 분석 — 캐주얼 캐릭터 일러스트 레퍼런스 해석 Agent

> 조사 기준일: 2026-09-21
> 목적: 이미 존재하는 이미지 생성·검색·포즈 연습·3D 포징 서비스와 기능을 과장해 비교하지 않고, UH케그려가 해결할 좁은 문제를 정한다.

## 1. 비교 대상과 핵심 문제

사용자는 캐주얼 캐릭터를 그리며 다음처럼 일상어로 요구를 말할 수 있다.

> 아래에서 올려다 보는 느낌으로 힙한 스타일의 포즈를 그리고 싶은데 광각으로 그리고 싶어.

초보자는 `low angle`, `foreshortening`, `wide-angle perspective` 같은 검색어와 이들이 각각 포즈·시점·원근 중 어디에 속하는지 알기 어렵다. 따라서 같은 단어를 여러 번 바꾸어 검색하거나, 서로 다른 레퍼런스를 어떻게 조합할지 결정하지 못한다.

UH케그려의 문제 정의는 **이미지를 더 잘 생성하거나 보유하는 것**이 아니다. 사용자의 모호한 문장을 기초 드로잉 용어와 선택적 탐색 계획으로 바꾸는, 레퍼런스 탐색 전 단계의 해석 문제다.

## 2. 조사 방법과 해석 원칙

- 아래의 **직접 관찰**은 기준일에 각 서비스의 공개 시작 화면 또는 기본 대화 화면에서 확인했다.
- 범용 LLM·Pinterest에는 위 문장을 그대로 입력했다. Line of Action·Quickposes·3D 포저는 자연어 입력 서비스가 아니므로, 같은 문장을 전송하는 대신 시작 흐름과 필요한 수동 입력을 확인했다.
- 로그인, 유료 기능, 라이브러리 전체, 장시간 조작은 시험하지 않았다. 따라서 “시작 흐름에서 보이지 않았다”를 “해당 기능이 절대 없다”로 해석하지 않는다.
- 생성형 모델의 결과와 서비스 UI는 시점·모델·계정 상태에 따라 바뀔 수 있다. 이 문서는 1회 탐색 결과이지, 성능 순위나 정량 벤치마크가 아니다.

## 3. 직접 관찰 결과

| 경쟁군 | 서비스 | 시작 흐름 또는 원문 입력 결과 | 사용자에게 남는 일 | UH케그려와의 관계 |
| --- | --- | --- | --- | --- |
| 범용 LLM | [ChatGPT](https://chatgpt.com/) | 원문을 입력하자 이미지 생성 흐름으로 해석되어 이미지 1장을 반환했다. 확인 가능한 전문 용어, 역할별 검색어, 외부 탐색 링크는 보이지 않았다. | 이미지를 참고해 포즈·시점·원근을 스스로 해석한다. | 대체재 일부. 우리 서비스는 이미지 생성 없이 용어와 탐색 계획을 고정 형식으로 제공한다. |
| 범용 LLM | [Claude](https://claude.ai/) | 원문에 대해 `3점 투시`, `foreshortening`을 중심으로 긴 설명과 시각 구조를 제시했다. 출처 상태, 선택 역할, Pinterest 링크는 구조화되어 있지 않았다. | 설명에서 필요한 요소를 골라 검색어로 다시 바꾼다. | 대체재 일부. 자연어 설명은 가능하지만, 우리 서비스의 검증된 term ID·선택 역할·링크 계약과는 다르다. |
| 범용 LLM | [Gemini](https://gemini.google.com/) | Gemini Flash 기본 화면에서 원문을 이미지 생성으로 해석해 이미지 1장을 반환했다. 용어 분해·링크는 보이지 않았다. | 이미지를 참고해 필요한 조건을 재해석한다. | 대체재 일부. 우리 서비스는 텍스트 우선이며 이미지를 생성하지 않는다. |
| 이미지 탐색 | [Pinterest](https://kr.pinterest.com/) | 로그인하지 않은 상태에서 원문 전체를 검색하자 “해당 검색어 관련 핀을 찾지 못했습니다”가 표시되었다. 자동 용어 교정이나 역할 분해는 관찰되지 않았다. | 긴 문장을 짧고 적절한 검색어로 다시 써야 한다. | 핵심 외부 탐색 대상. 우리 서비스는 Pinterest 결과를 수집하지 않고, 역할별 검색 링크만 만든다. |
| 제스처 연습 | [Line of Action](https://line-of-action.com/practice-tools) | `Figure Drawing`, `Hands & Feet`, `Faces & Expression` 등 연습 유형을 먼저 고르고, 제한 시간 제스처 드로잉을 안내한다. 자연어 요구 입력란은 시작 화면에서 보이지 않았다. | 어떤 연습 유형과 조건이 맞는지 알고 선택한다. | 보완재. 포즈 관찰·훈련에는 유용하지만, 모호한 문장을 탐색 용어로 바꾸는 서비스는 아니다. |
| 제스처 연습 | [Quickposes](https://quickposes.com/en) | `Challenges`, `Timed practice`, `Random poses`, `Library`에서 포즈 유형과 시간을 선택해 연습하는 흐름이다. 시작 화면에서 자유 문장 해석 기능은 보이지 않았다. | 연습할 포즈 범주와 시간을 직접 정한다. | 보완재. 제스처 연습 전, 사용자가 원하는 조건을 이해하도록 도울 수 있다. |

| 3D 포저 | [Magic Poser](https://magicposer.com/) | 공개 소개 화면에서 제어점을 드래그하는 포징, 체형 변형, 조명, 프리셋 포즈 라이브러리를 안내했다. 실제 앱 조작은 시험하지 않았다. | 앱에서 모델과 카메라·조명을 직접 구성한다. | 보완재. 원문 해석보다 3D 수동 제작에 중심이 있다. |

### 입력 문장에 대한 공정한 비교

이 문장을 모든 서비스에 똑같이 “입력”하는 것은 공정하지 않다. Pinterest·연습 서비스·3D 포저에는 원래 자유 문장 입력이 없거나 주된 진입 방식이 아니다. 따라서 이 조사에서 확인할 것은 다음 두 가지다.

1. 원문을 그대로 받는 서비스는 이를 어떤 작업으로 해석하는가.
2. 원문을 직접 받지 않는 서비스는 사용자가 작업을 시작하기 전에 어떤 선택과 번역을 직접 해야 하는가.

## 4. 우리 서비스가 맡을 단계

```text
사용자의 일상어
  → 허용된 기초 용어 후보와 짧은 설명
  → body / pose / view / perspective / layout 중 필요한 역할만 선택
  → 팀이 검수한 TERM_CARDS의 용어·한계 확인
  → 선택된 역할별 Pinterest 외부 검색 링크
  → 사용자가 Pinterest·연습 서비스·3D 포저에서 실제 레퍼런스를 고르거나 제작
```

예시 문장은 다음처럼 **후보와 조건**으로 응답한다.

| 사용자 표현 | 해석 후보 | 주의할 점 |
| --- | --- | --- |
| 아래에서 올려다보는 느낌 | `low angle` (view) | 카메라 높이와 시점에 관한 조건이다. |
| 광각 | `wide-angle perspective`, `foreshortening` (perspective) | 가까운 부분이 커 보이는 단축을 확인하는 후보이다. |
| 힙한 스타일의 포즈 | `dynamic pose`, `fashion pose` 등 탐색 후보 | “힙한”은 표준 단일 용어가 아니므로 단정하지 않고 사용자에게 후보로 제시한다. |
| 3점 투시 | 조건부 perspective 후보 | 카메라가 위·아래로 기울어 수직선 수렴이 필요한 경우에만 제안한다. `광각`만으로 자동 확정하지 않는다. |

이 구조에서 LLM은 일상어의 의미를 **허용된 term ID와 역할 선택 후보**로 바꾸는 데 쓴다. 최종 검색어 순서·URL 인코딩·허용 ID 검증은 결정론 코드가 담당한다. 용어의 단일 원본은 팀이 관리하는 TERM_CARD이며, Pinterest에는 HTTP 요청·스크래핑·이미지 재게시를 하지 않는다.

## 5. 경쟁 우위와 범위의 경계

### 주장할 수 있는 차별점

- 한 문장의 요구를 체형/소체, 포즈, 시점, 원근, 배치 중 **필요한 역할만** 분리한다.
- 초보자에게 짧은 용어 설명과 왜 이 용어를 제안했는지를 함께 제공한다.
- 용어의 출처 또는 폴백·한계를 표시하고, Pinterest 결과가 이미 확보된 것처럼 주장하지 않는다.
- 이미지 생성·이미지 카드·스크래핑 없이 외부 탐색 링크만 제공하므로, 사용자가 원 출처에서 결과를 직접 확인한다.

### 주장하면 안 되는 내용

- Pinterest보다 더 좋은 이미지 또는 더 많은 이미지를 찾는다고 주장하지 않는다.
- 범용 LLM이 전문 용어 설명을 전혀 못 한다고 주장하지 않는다.
- Line of Action·Quickposes·PoseMy.Art·Magic Poser에 자연어 기능이 절대 없다고 단정하지 않는다. 이번 조사에서는 공개 시작 흐름에서 확인되지 않았을 뿐이다.
- TERM_CARD를 캐릭터 포즈 이미지 데이터베이스 또는 Pinterest 대체재로 표현하지 않는다.

## 6. MVP 화면과 평가에 반영할 점

### MVP 응답 화면

1. 사용자 원문과 “이렇게 해석했어요”를 먼저 보인다.
2. 선택된 역할만 `body → pose → view → perspective → layout` 순서로 카드가 아닌 텍스트 블록으로 보인다.
3. 각 역할에 용어, 초보자용 뜻, 근거·confidence·limitation, Pinterest 외부 링크를 표시한다.
4. 미선택 역할은 빈 검색어·빈 링크를 만들지 않는다.
5. Pinterest 검색 결과나 이미지 품질을 에이전트의 성과로 표시하지 않는다.

### 후속 평가 설계

이 1회 경쟁 조사는 질적 근거다. 프로젝트 평가에서는 같은 입력 묶음에 대해 다음을 측정한다.

| 지표 | 측정 방식 |
| --- | --- |
| 역할 분리 사람 평가 | 검토자 2명이 필요한 역할만 선택됐는지 독립 평가한다. |
| 용어 제안 적절성 | 허용 term ID, 설명, 조건부 표현이 도메인 검토와 일치하는지 확인한다. |
| 검색어 재작성 횟수 | 사용자가 첫 링크 후 검색어를 다시 바꾼 횟수를 기록한다. |
| 추가 질문 수 | 사용자가 필요한 용어·검색 방향을 얻기까지 한 추가 질문 수를 기록한다. |
| 계약 준수율 | 선택 역할 순서, term ID 검증, 출처·limitation 표시, URL 생성 규칙을 자동 검사한다. |

이미지 수, Pinterest 검색 결과의 품질, 생성 이미지의 미적 완성도는 이 MVP의 책임 범위가 아니므로 핵심 지표에서 제외한다.

## 7. 결론

UH케그려는 이미지 생성기·이미지 검색 서비스·포즈 연습 서비스·3D 포저를 대체하지 않는다. 이 서비스들이 유용해지기 직전의 병목, 즉 **초보자가 머릿속 요구를 전문 용어와 검색 가능한 조건으로 표현하지 못하는 문제**를 해결한다.

따라서 제출·발표에서는 “AI가 이미지를 찾아 준다”보다 “초보자의 모호한 설명을 근거와 한계를 포함한 역할별 탐색 언어로 바꾼다”를 핵심 가치로 제시한다.
