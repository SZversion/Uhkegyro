# Illustration Reference Domain Profile

| 항목 | 현재 확인된 내용 |
| --- | --- |
| 프로젝트 한 줄 정의 | 초보자가 텍스트로 묘사한 캐주얼 캐릭터의 체형/소체·포즈·구도를 기초 드로잉 용어와 역할별 탐색 계획으로 바꾼다. |
| 핵심 사용자 | 캐주얼 캐릭터 일러스트를 시작했고 전문 용어가 낯선 사용자 |
| 고객 여정 | 모호한 텍스트 의뢰 → 넓은 검색어 반복 → 체형·포즈·구도 조건 분해 → 역할별 탐색과 관찰 |
| 당사자 경험 | 오세창, 프리랜서 캐주얼 캐릭터 일러스트 약 3년. 러프 단계에서 조건을 나눠 여러 레퍼런스를 병렬로 확인한다. |
| 고유 워크플로우 | 입력 충족도 → 체형/소체 → 지지점과 포즈 → 인물 시점·배경 원근·배치 → 선화 이후 세부 |
| 입력과 출력 | 1~500자 텍스트와 비식별 ID → 용어 선택·근거·불확실성·역할별/통합 Pinterest 탐색 링크 |
| 도메인 데이터/MCP | Getty AAT SPARQL로 용어 후보 URI·label을 조회하고, 권리 검토된 자체 카탈로그 메타데이터는 별도 FastMCP로 조회한다. AAT는 이미지 카탈로그가 아니며 현재 자체 카탈로그 레코드·권리 승인 기준은 미정이다. |
| 경쟁 서비스 | ChatGPT/Claude/Gemini, Quickposes/Line of Action, PoseMyArt/MagicPoser, Pinterest |
| 성공 지표 | 허용 term ID/역할 순서 계약 준수율, 역할 분리 사람 평가, 검색어 재작성 횟수, 추가 질문 수 |
| 범위와 비범위 | 텍스트 해석·외부 탐색 링크는 포함. 이미지 생성·분석·수집·재게시·스크래핑·RAG·화풍 복제는 제외. |
| 승인 담당자 | 용어·사례: 오세창. 카탈로그 권리·배포: 팀 리더 또는 합의 담당자. |

> 카탈로그 최소 레코드 수와 권리 검토 기준은 아직 승인되지 않았으며, 구현/제출 완료로 주장하지 않는다.
